# Good Thinking Bot

Interactive critical thinking tutor that teaches logic, decision theory, game theory, and economics through scenario-based practice with NPC characters.

**Authors:** Bert Baumgaertner & Nicholas Potter, University of Idaho

## Features

- **Interactive Tutor**: Random scenarios with NPC characters. Analyze the reasoning, then see the correct answer with a rubric for self-assessment.
- **Practice by Topic**: Select a specific taxonomy code (e.g., "A7.1: Ad hominem") and work through all examples.
- **182 taxonomy codes** across six tracks: Logic & Critical Thinking, Decision Theory, Game Theory, Cognitive Biases, Microeconomics, and Dennett's Thinking Tools.
- **Three difficulty tiers**: Drill, What-If, and Puzzle.
